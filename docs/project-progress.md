## 5. 当前限制

- 当前没有真实模型供应商配置，`provider_integration` 和 `ai_quality` 暂不判定通过。
- 当前没有容量压测机，`capacity_certification=not_run`。
- 当前未获镜像元数据外发授权，镜像漏洞扫描为 `not_configured`；Linux 宿主机验收为 `not_run`，两者阻断正式发布但不阻断本地功能建设。
- 上述限制不阻塞阶段 0 的契约、功能链路和小规模本地技术验证。

## 6. 更新规则

节点状态、验收证据和提交信息按 [交付、文档与 Git 管理规范](./governance/delivery-and-git.md) 更新。每次节点提交完成后，本看板必须回填短 SHA；为了避免用修改历史的方式伪造追溯，SHA 回填可随下一个节点提交进入 Git，阶段关闭前必须全部核对。
