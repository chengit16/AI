## 5. 更新规则

节点状态、验收证据和提交信息按 [交付、文档与 Git 管理规范](./governance/delivery-and-git.md) 更新。每次节点提交完成后，本看板必须回填短 SHA；为了避免用修改历史的方式伪造追溯，SHA 回填可随下一个节点提交进入 Git，阶段关闭前必须全部核对。
